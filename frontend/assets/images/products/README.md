# Product photos

Put one photo per product in this folder, **named by product ID**: `<id>.jpg` (or `.jpeg`, `.png`, `.webp`).
The server detects them automatically on the next page load. No code changes are needed.
Products without a photo show a neutral icon tile, so nothing breaks while you add them.

Tips: landscape or square, about 800x600 px or larger, product on a clean background, and make sure you
have the right to use the image (your own photos, or images licensed for reuse such as Wikimedia Commons / Unsplash / Pexels).

The server prints `Product photos found: N/100` at startup so you can track progress.
